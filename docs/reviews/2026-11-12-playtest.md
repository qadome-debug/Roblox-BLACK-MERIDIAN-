# Play-test review — 2026-11-12

Build: `main` at BM-020 (commit d1259dd). Tested in Roblox Studio 0.747
with Play (solo), plus the automated suite (147 tests, `check-all` green).

## What a player sees today

An empty baseplate-less sky and a falling avatar. There is no world, no
combat, no Cant, no quest, no UI. That is expected: the plan's first twenty
tasks are infrastructure, and the first playable content is Phase C/D
(BM-051 onward, vertical slice at BM-096).

## What works (verified)

- Server boots in order: config → logging → remotes (audited) → sessions,
  limiter, dispatcher → player events. Output shows
  `server_bootstrap_loaded` and `server_ready`.
- Client joins, receives its session epoch over `StateDelta`, sends
  `ClientHello`, and the server answers `OK` with a rotated epoch:
  `session_ready` and `request_ok action=ClientHello` on the server,
  `Client session ready` / `Client handshake complete` on the client.
- Every rejection path of the ingress is covered by tests; nothing a client
  sends can reach a gameplay service that does not exist yet.

## Improvements, in priority order

1. **Supply the canonical content inventory.** Regions, quests, Cants,
   Verses, Burdens, Waymarks, bosses, Descents with their real names. Every
   content task from BM-062 on is blocked on it, and the registry already
   validates whatever is added.
2. **Enable branch protection on GitHub** (docs/ci.md) so a red CI run
   actually blocks a merge.
3. **Phase B next (BM-021–050): profiles, leases, receipts.** Nothing
   permanent can be granted until this exists; it is also the longest
   security-critical stretch.
4. **Studio-side smoke test script.** A ServerStorage test that exercises
   the handshake inside Studio automatically on Play, so the manual Output
   check becomes an assertion.
5. **Periodic remote audit** (currently only at start) and a client-side
   watchdog for `STALE_EPOCH` that triggers a reconnect prompt.
6. **A visible placeholder world** (spawn platform, Waymark I marker) so
   play-tests have something to stand on before the first region lands.
